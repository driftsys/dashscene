**Hand-constructed, the package's own layer block removed.** No player on
this device fails to draw, so a real dump never lacks the layer — the case
`read_timestats` must still cover, per `measure/android/fixtures/README.md`:
a missing layer reads as unreadable in `unity-cpu.md`, never as a row of
zeroes. Only the "none" layer other apps' compositor traffic produces is
left, matching what a real dump carries when the package is not yet drawing.
