# dashscene

dash turns UI designed in Figma — or authored programmatically in code —
into pixels on screen, through one intermediate representation, one shared
layout+text runtime, and interchangeable paint backends.

This book is generated from the same source that lives in this repository's
`specs/` addenda. See [Design](./design.md) for the architecture and
[Scope decisions](./scope-decisions.md) for what's been decided since.
